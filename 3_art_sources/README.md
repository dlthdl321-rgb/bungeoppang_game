# 이미지 제작 원본

게임에 적용하기 전의 이미지 원본·시안·제작 자료입니다. **현재 게임에서 사용하는 에셋은 `1_game_app/assets/`입니다.** 이 폴더의 이미지를 바꿔도 게임에 자동으로 반영되지 않습니다.

| 위치 | 무엇을 찾을 때 보는가 |
| --- | --- |
| `bungeoppang_raw_assets_261007_0114_01/` | 날짜별 원본 패키지와 매니페스트 |
| `붕어빵게임_개발에셋_261006_1905_01/` | 초기 개발 시안과 화면 구성 자료 |
| `추가 생성 이미지/` | 추가 이미지 원본과 목록 |
| `추가 생성 이미지 2/` | 후속 추가 이미지·생성 진행 기록 |

[이미지 제작 문서·갤러리](../2_game_planning_and_checklists/2.2_art_creation_guides_and_galleries/) · [이미지 적용 도구](../1_game_app/tools/README.md)

원본 파일명과 내부 폴더명은 매니페스트·제작 도구가 참조하므로 유지합니다. 게임 반영은 적용 도구와 `1_game_app/assets` 변경 내용을 확인하며 진행합니다.

동일 바이트의 중복 `raw/`·`preview/` 복사본은 제거했습니다. 표준 원본과 미리보기는 `bungeoppang_raw_assets_261007_0114_01/raw/`·`preview/`에서 확인합니다. 초기 시안 폴더의 중복 매니페스트도 표준 패키지의 `manifest.json`으로 통합했습니다. 이름이 다른 시안 원본과 수정 전 백업은 제작 이력을 위해 유지합니다.
