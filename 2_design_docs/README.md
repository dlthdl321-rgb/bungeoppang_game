# 저장소 문서 안내

## 폴더 번호 규칙

Git으로 관리하는 문서는 이 안내에서 전체 목록을 관리한다. 저장소 전체 폴더 구조는 [루트 안내](../README.md)를 따른다. 문서 폴더는 `번호_이름`, 하위 폴더는 `상위번호.번호_이름`을 사용한다. 파일명·문서 내부 제목·REQ/DEC/P 작업 ID는 유지한다. 이미지·게임 에셋·코드·작업 데이터(JSON)·ZIP 자체는 문서 이동과 분리해 원래 위치에 유지한다.

| 번호 | 폴더 | 내용 |
| --- | --- | --- |
| 2.1 | [2.1_planning](2.1_planning/README.md) | 현재 기획·결정·단계·검수와 보존 문서 |
| 2.2 | [2.2_art](2.2_art) | 이미지 제작 안내와 갤러리 |
| 2.3 | [2.3_reports](2.3_reports) | 이미지 작업 완료 기록과 백업 안내 |
| 2.4 | [2.4_platform](2.4_platform) | 플랫폼별 개발 안내 |
| 2.5 | [2.5_archives](2.5_archives/README.md) | 저장소 보관 파일 안내 |
