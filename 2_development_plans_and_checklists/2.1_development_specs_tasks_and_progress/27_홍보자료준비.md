# 27. 홍보 자료 준비 — 짧은 영상·스토어 문구·스크린샷

작성: 2026-11-19, [26번 8단계](26_흥행개선단계별프롬프트.md)(DEC-048). 코드가 아니라 사람이 직접 하는 홍보 준비 문서다. 게임 안 공유 카드(완벽 결과·이야기·도감 완성·가게 사진)는 MASTER 35장을 본다.

이 문서의 스토어 문구는 **초안**이다. 23번 8단계(정책 문서·스토어 등록)가 아직이라, 23번 8단계를 할 때 이 초안을 가져가 Play Console에 붙여 넣을 최종본으로 다듬는다.

## 1. 짧은 영상 대본 3개 (15~30초, 세로 화면)

모두 같은 흐름을 쓴다: **색칠(반죽 붓기) → 원 그려 뒤집기 → 완벽 판정 → 손님 반응**. 첫 2초 안에 붕어빵이 화면에 보여야 넘기지 않는다. 글자는 화면 위쪽 1/3에 크게, 한 장면에 한 줄만.

### 대본 A — "완벽한 붕어빵 한 마리" (20초)

| 초 | 화면 | 화면 글자 | 소리 |
| --- | --- | --- | --- |
| 0~2 | 빈 붕어빵 틀 가까이 | 붕어빵, 직접 구워 볼래요? | 굽는 소리 시작 |
| 2~6 | 손가락으로 반죽을 쓱쓱 칠함(틀이 노랗게 채워짐) | 반죽은 색칠하듯 | 게임 소리 그대로 |
| 6~9 | 팥 소를 짜 넣음 → 위 반죽 → 뚜껑 닫기 | 팥 듬뿍 | |
| 9~13 | 틀 둘레에 손가락으로 원을 그려 뒤집음 | 원을 그리면 뒤집혀요 | 뒤집는 소리 |
| 13~16 | 꺼내기 → '완벽해요!' 반짝임 | 완벽! | 완벽 효과음 |
| 16~20 | 기다리던 손님이 웃으며 말풍선 | 단골손님 반응까지 | 배경음악 |

### 대본 B — "망한 붕어빵 vs 완벽한 붕어빵" (25초)

| 초 | 화면 | 화면 글자 |
| --- | --- | --- |
| 0~3 | 반죽을 너무 많이 칠해 넘친 붕어빵 결과('아깝다!') | 이렇게 되면 아깝고… |
| 3~6 | 너무 늦게 꺼내 '타버림' 결과 | 늦으면 타요 |
| 6~15 | 다시 한 번: 고르게 색칠 → 소 → 닫기 → 원 그려 뒤집기 | 이번엔 제대로 |
| 15~19 | 딱 맞게 꺼내 '완벽해요!' | 완벽! |
| 19~25 | 손님 반응 → '자랑하기'로 공유 카드가 뜸 | 카드로 자랑까지 |

### 대본 C — "작은 가게의 하루" (30초)

| 초 | 화면 | 화면 글자 |
| --- | --- | --- |
| 0~3 | 홈 화면 전체(가게 배경·등불·손님) | 오늘도 붕어빵 가게 문을 엽니다 |

## 2. 휴대폰 화면 녹화 방법 (안드로이드, 처음 하는 사람용)

1. **녹화 전 준비**
   1. 휴대폰 위에서 아래로 쓸어내려 빠른 설정을 연다. **방해 금지**를 켠다(녹화 중 메시지 알림이 화면에 뜨지 않게).
   2. 게임 설정에서 **손님 알림**을 잠시 끈다(녹화 중 알림 팝업 방지). 녹화가 끝나면 다시 켠다.
   3. 휴대폰 화면 밝기를 최대로, 배터리 절약 모드는 끈다(화면이 어두워지지 않게).
   4. 게임을 녹화하기 좋은 상태로 만든다: 손님이 매대에 1~2명 있고, 반짝이는 장식을 걸어 둔 상태.
2. **녹화 시작**
   1. 빠른 설정을 한 번 더 쓸어내려 전체를 펼친다. **화면 녹화**(삼성은 '화면 녹화', 픽셀은 '화면 녹화') 타일을 누른다. 없으면 빠른 설정의 연필(편집) 버튼을 눌러 '화면 녹화'를 끌어다 놓는다.
   2. 소리 설정에서 **미디어 소리**(또는 '기기 소리')를 고른다. 마이크는 끈다(주변 소리가 들어가지 않게).
   3. '터치 표시'가 있으면 켠다(손가락으로 원을 그리는 게 보여야 이해가 쉽다).
   4. 시작을 누르고 3초 카운트가 끝나면 게임으로 돌아가 대본대로 플레이한다.
3. **녹화 끝**: 빠른 설정을 내려 녹화 알림의 **중지**를 누른다. 영상은 갤러리의 'Screen recordings'(화면 녹화) 앨범에 저장된다.
4. **자르기**: 갤러리에서 영상을 열고 **편집(연필)** → 앞뒤 필요 없는 부분을 잘라 15~30초로 맞춘다. 글자는 CapCut 같은 편집 앱이나 각 SNS 앱의 '텍스트'로 넣는다.

### 영상에서 피해야 할 것

- **개발자 메뉴**·디버그 글자(개발용 빌드의 시간 이동·되돌리기 버튼 등). 녹화는 반드시 **Play에서 받은 테스트 빌드**로 한다.
- **임시 그림**: 25번 문서에서 '미생성'인 그림(동그라미 이니셜로 나오는 손님, 단색 상자 등)이 화면에 나오는 장면.
- 알림 팝업, 상태 표시줄의 메신저 아이콘, 배터리 부족 경고.
- 내 카카오 이름·이메일이 보이는 설정 화면, 결제 화면(실제 금액·카드 정보).
- 너무 빠른 조작(보는 사람이 따라오지 못함). 원 그리기는 천천히 한 바퀴.

## 3. 스토어 문구 초안 (23번 8단계가 가져가 최종본으로)

- **앱 이름**(30자 이내): 오늘의 붕어빵
- **짧은 설명**(80자 이내, 지금 50자): `색칠하듯 반죽 붓고 원 그려 뒤집는 붕어빵 가게! 완벽한 한 마리로 단골손님을 웃게 해요.`
- **긴 설명 초안**(4000자 이내):

```text
찬바람 부는 골목, 작은 붕어빵 가게의 사장님이 되어 보세요.

■ 손으로 굽는 붕어빵
반죽은 색칠하듯 틀에 쓱쓱, 소는 듬뿍, 뚜껑을 닫고 틀 둘레에 원을 그리면 휙 뒤집혀요.
알맞은 때에 꺼내면 '완벽해요!' — 겉은 바삭, 속은 촉촉한 한 마리가 완성됩니다.

■ 단골손님과 이야기
퇴근길 윤하 씨, 간식 지도를 들고 오는 도윤이, 막례 할머니…
자주 찾아오는 손님마다 좋아하는 맛과 이야기가 있어요. 하루에 한 조각씩 이어지는 이야기를 들어 보세요.

■ 6구 굽는 판과 가게 키우기
맛을 숙련하면 6구 굽는 판이 대신 구워 줘요. 스킬을 올려 더 많이, 더 빨리 구워 보세요.
팥에서 시작해 슈크림, 초코까지 새 맛을 열 수 있어요.

■ 매일 들르고 싶은 가게
오늘의 주문서, 출석 도장, 겨울 행사(첫눈·크리스마스·설날) 장식이 가게를 찾아와요.

■ 사장님과 가게 꾸미기
머리 모양, 옷, 앞치마를 바꾸고, 가게 배경과 장식을 골라 나만의 가게를 만드세요.

■ 자랑하기
완벽하게 구운 붕어빵, 손님 이야기, 다 채운 도감, 우리 가게 모습을 예쁜 카드로 친구에게 보여 주세요.

* 게임 안 일부 아이템은 유료로 살 수 있어요(황금붕어빵력).
* 개인정보처리방침: (23번 8단계에서 올린 공개 주소)
```
