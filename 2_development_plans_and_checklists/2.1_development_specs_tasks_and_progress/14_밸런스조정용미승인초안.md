# 밸런스 조정용 미승인 초안

2026-10-16 / P1-002 후속. 사용자는 **출시값을 확정하지 않고 초안을 작성하는 방식**을 승인했다. 아래 가격·횟수·확률·레벨은 전부 미승인이며 게임 설정/상품/서버에 적용하지 않았다. 기존 직원2·4 추천에서 비교용 후보를 모았다. 문서의 정수 계산과 실제 플레이 시뮬레이션은 다르다. 게임/서버 테스트·빌드·실기기·경제 시뮬레이션은 **미실행**이다.

## 1. 변경하지 않는 확정 조건

팥 미디엄 레시피로 구매 없이 핵심 진행. 다른 익힘은 직접 수집, 맛별 숙련은 연습5종 AND 연습량 AND 손기술 통과량. 실패 완주 연습 포함·주문은 수집만. 유상 상품/스킬은 두 잔액 AND·온라인 구매. 오프라인 판매도 연결 후 황금 심사, 검증된 판매에만1회 추첨. 광고는 로그인 계정별 하루최대2회·KST 시작일 귀속이다. 광고 중 세 타이머 정지도 확정이며 추가 수급 보너스로 바꾸지 않는다.

## 2. 가격 비교 후보

| 항목 | 붕어빵력 후보 | 황금 후보 | 근거/미정 |
| --- | ---: | ---: | --- |
| 첫 탭 스킬 | 15 | 1 | 직원4 후보. 실제 첫 구매 지연 검증 전 승인하지 않음 |
| 첫 자동 스킬 | 50 | 1 | 직원4 후보. 단일 재화의 현재 코드 가격과 구분 |
| 반복 소비/꾸미기/레시피 | 항목별 대기 | 항목별 대기 | 누락 항목을 무료0으로 채우지 않음. 이미 보유한 권리 재구매 금지 |

스킬 후보: n은 구매 전 보유 회차(0부터), P(n)=ceil(B×(115/100)^n), H(n)=G+floor(n/10). 비교 대안은 황금 H(n)=G 고정이다. 금액은 **개별 정수 올림 후 합산**, 묶음/최대구매는 두 합계와 두 가용 잔액을 모두 확인한다. 소수 계산을 실제 재화 저장 타입으로 도입하지 않는다.

B=15, G=1 후보의 산술 예: 처음2개는 붕어빵력33·황금2, 처음10개는 붕어빵력308·황금10, 다음10개는 붕어빵력1238·황금20이다. 이 계산은 식의 일관성만 확인하며 해당 가격이 적절하거나 구현됐다는 증거가 아니다. 황금 고정 대안에서 다음10개 황금은10이다.

## 3. 숙련·시간 후보

| 후보 난이도 | 인정 연습량 후보 | 손기술 통과량 후보 | 확정하지 않은 점 |
| --- | ---: | ---: | --- |
| 낮음 | 8 | 3 | 맛별 난이도 대응·손기술 세부 판정 |
| 중간 | 12 | 4 | 주문 제작은 두 카운터에 합산하지 않음 |
| 높음 | 16 | 5 | 초기 핵심 플레이가 구매 없이 가능한지 비교 필요 |

모든 익힘5종을 **연습에서** 모으는 조건과 함께 충족해야 한다. 횟수를 채웠거나 실패만 반복했다고 손기술 조건을 면제하지 않는다. 손기술의 반죽 범위·오입력 허용·익힘 요구는 미정이다.

익힘 시간 비율 후보는 T>0, t≥0에서 [0,0.6T), [0.6T,0.9T), [0.9T,1.1T), [1.1T,1.4T), [1.4T,∞). 왼쪽 포함·오른쪽 제외로 빈틈/중복을 피하는 후보이며 T·단계 명칭·미디엄 대응은 확정하지 않는다. 기존 ‘7단계’나 임의 고정10초를 복원하지 않는다. 덜 익음 특별 주문의 판매 허용을 손기술 자동 통과나 6구 수확 허용으로 확대하지 않는다.

## 4. 황금 수급·첫 구매 비교 후보

| 경로 | 후보 | 주의할 해석 |
| --- | --- | --- |
| 광고 | 회당 황금1 | 하루2회는 확정, 회당1은 미승인. 실제 광고 재고·로그인·검증 성공을 보장하지 않음 |
| 판매 희귀 | 별1~5를 가정한 확률1~5%, 당첨 황금1 | 별점 최저/단위·산식 미정. 별5개도100% 아님 |
| 판매 보상 상한 | 황금10/보상일 | 미승인 후보이며 광고 한도/영업일과 섞지 않음. 새 확정 상한으로 적용하지 않음 |
| IAP | 기존 gold_*와 실제 결제 구조 유지 | 새 현금 환율·상품·시작 황금 보너스를 만들지 않음 |

정수 별1~5 가정이 달라지면 확률 표를 다시 작성한다. 신선도가 만족도에 이미 반영됐다면 황금 확률에 임의로 두 번 곱하지 않는다. 특별 주문이 덜 익음을 요구했다는 이유만으로 저평가·황금 제외를 자동 적용하지 않는다.

당첨 확률 p가 고정되고 매회 같은 자격·독립 추첨이라고 **가정한** 첫 당첨까지 기대 판매 수는1/p(1%면100건,5%면20건)이다. 이는 상한/확정 보장 시간이 아니며 심사 거절·지연·자격 제한이 있는 실제 경로의 예측값도 아니다. 광고를 안 보는 무과금 경로에서 첫 구매를 확정 보장하는 정책은 새로 승인되지 않았다. 구매 지연과 핵심 진행 막힘을 분리하고, 핵심 진행을 유상 구매로 다시 잠그지 않는다.

## 5. Lv.50·기능 해금 비교 후보

직원4 후보 식은 목표 레벨 L=2~50, d=L−1에서 누적 목표 C(L)=100×d²×(1+floor(d/10)), 레벨 구간 직접 탭 T(L)=30+10×floor((L−2)/5), 판매 S(L)=1+floor((L−2)/10)이다. 새 시즌 누적 기준과 기존 lifetime 보존을 분리한다. 이 식과 탭/판매의 필수 여부·구간 초과분 처리도 **미승인**이다.

기능별 실제 해금 레벨표는 이번에 출시값으로 만들지 않는다. 구매/광고를 승급 필수 조건으로 넣지 않는 직원4 제안, 기능의 영구 접근권 유지, 환생 후 재잠금 여부는 별도 승인 대기다. 기존 기능/구매 권리를 이전할 때의 처리는 [13번 위험 검토](13_저장이전과구매복구위험검토.md)가 선행이다.

## 6. 조정·채택 절차

1. 제작의 실제 소요·주문 대기·초기 숙련·원하는 성장 속도·출시 콘텐츠 수를 먼저 합의한다. 신규 납기/목표 시간을 추정해 확정하지 않는다.
2. 광고 미시청·희귀 미당첨·심사 지연/거절·낮은 숙련·광고2회 이용 경로를 분리해 비교한다. 초안 후보마다 버전을 붙이고 실제 비교 증거를 남긴다.
3. 두 재화 소비, 판매/광고/IAP 수급, 직접 조작 부담, 첫 스킬 구매 지연과 Lv.50 도달 곡선을 함께 검증한다. 산술 표만으로 소요일수나 재미를 보장하지 않는다.
4. 사용자 채택과 실행 검증 전 가격·시간·확률을 출시 설정/테스트 기대값으로 고정하지 않는다. 채택된 범위만 DEC·가격/규칙 버전에 반영한다.
