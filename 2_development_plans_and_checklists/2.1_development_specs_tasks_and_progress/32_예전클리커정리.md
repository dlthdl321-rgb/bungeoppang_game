# 32. 예전 클리커 코드 정리 (DEC-155)

작성 2026-11-25 · 승인 [DEC-155](2.1.1_game_rules_and_decisions/00_결정취합.md) · 브랜치 `dev/stabilization`

GameController는 예전 클리커 게임(탭·콤보·레벨·미션·주간·업적·환생·코인·부스트·초대 코인)과 지금 게임이 쓰는 계정 기능(설정·온라인·친구·랭킹·황금 결제·사용 통계·예전 꾸미기 착용)을 함께 갖고 있다. 새 게임에서 안 쓰는 쪽을 지운다. **계정·온라인·결제·설정은 남긴다.**

## 1. 발견한 실제 문제 [확인: 코드 추적]

`CelebrationHost`(`ui/game_app.dart`)가 100ms마다 예전 게임 목표(`claimableGoals`)를 확인한다. 예전 주간 목표 '3일 동안 노점 열기'는 플레이한 날만 세므로, 새 홈에서도 3일 뒤 "미션 달성 · 주간 도전" 알림이 뜰 수 있다. 1단계에서 없앤다.

## 2. 단계 (단계마다 테스트·커밋, 기준 이미지 59장은 바뀌면 안 됨)

| 단계 | 내용 |
| --- | --- |
| 0 | 공용 도구 옮기기(동작 변화 없음): 숫자 표기 → `number_format.dart`, 스킬 목록 → `skill_catalog.dart`, 반짝임·6구 그림 자르기·서버 모양·숫자 올라가기 위젯을 각자 쓰는 곳으로 |
| 1 | 새 화면에서 예전 경로 끊기: `CelebrationHost` 제거(1절 문제), 메뉴의 주간·보상 계산, 코인 꾸미기 구매, 예전 부스트 표시, 예전 랭킹 판 기본값 |
| 2 | GameController 줄이기: 탭·콤보·레벨·미션·주간·업적·환생·오프라인 보상·초대 코인·부스트·예전 랭킹 제출 제거. 온라인 동기화 주기·정산 대기(`_away`)는 남김 |
| 3 | 계정 저장 formatVersion 15: 남는 필드(설정·황금·예전 꾸미기·스킨·순번)만 쓰고, 옛 저장(1~14)은 예전 필드를 무시하고 읽는다. 옛 견본 `account_format14.json`은 계속 읽기 검사 |
| 4 | 안 쓰게 된 lib 파일과 예전 게임만 검사하던 테스트 파일 삭제, `main.dart`에서 닿지 않는 파일이 없는지 확인 |
| 5 | 서버와 맞추는 값(`catalog.json` 소비 목록, 랭킹 판 이름) 정리 |
| 6 | (서버 배포 때) 서버의 예전 랭킹 판·코인 소비·초대권 정리 |
