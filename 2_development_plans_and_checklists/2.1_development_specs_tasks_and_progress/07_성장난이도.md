## 현재 코드에서 확인한 원인

`lib/economy_config.dart`의 탭 3단계 효과는 구매당60인데 4단계는600으로10배, 자동3단계는초당100에서4단계1000으로10배 오른다. 특히 탭3·4단계 해금 누적 조건은 둘 다10,000이라4단계가 곧바로 경쟁한다. 5단계 이후 효과는 약5.65배, 가격은10배씩 오른다. 큰 숫자의 증가는 확인했지만 실제 플레이가 얼마나 빠른지는 이번에 측정하지 않았다.

`lib/mission_config.dart`의 현행 offline-v1에는 단계별 직접 탭 조건이 없다. 자동 생산 중심 조건만으로도 일부 레벨을 통과할 수 있다. 레벨을 올릴 때 수령 버튼을 누르는 것은 직접 탭 성장으로 계산하지 않는다. 기존 테스트의2회/초 정책은 시험 조건이며 사용자의 실제 속도로 간주하지 않는다.

## 기존 밸런스 초안 — 완만한 생산과 직접 탭 목표

### 스킬 효과 곡선

스킬ID/기존보유수는보존한다. 아래효과/누적해금표는개정전초안이며새복합구매와함께재검증한다. 가격은붕어빵력AND황금붕어빵력의항목별금액/반복증가를새로정해야하므로과거단일가격유지를확정하지않는다. 부스트/환생의기존계산을기반으로검증하되50레벨환생정책은미정이다.

| 스킬 단계 | 탭 효과: 현재 → 후보 | 자동 효과/초: 현재 → 후보 |
| --- | ---: | ---: |
| 1 | 1 → 1 | 1 → 1 |
| 2 | 8 → 5 | 10 → 2 |
| 3 | 60 → 20 | 100 → 4 |
| 4 | 600 → 70 | 1,000 → 8 |
| 5~16 | 기존 단계별 표 → 직전 후보 효과의3배 | 기존 단계별 표 → 직전 후보 효과의1.5배를 올림 |

사용자의 자동 생산 속도 완화 요청에 따라 자동 효과 후보를 추가 하향했다. 탭은5단계210·6단계630을 유지하고, 자동은5단계12·6단계18로 조정한다. 자동5단계 이후는 `다음 효과 = (직전 효과×3+1) ÷ 2의 정수 몫`으로 계산한다. 내부 계산은 정수·BigInt로 한다. 효과 감소로 기존 후반 레벨의 초당 목표가 지나치게 멀어지므로 **현재 Lv.5~10 목표를 그대로 둔 채 효과만 낮추는 적용은 금지**한다. 목표와 도달 시간을 함께 재산정한 뒤 새 밸런스 버전으로 적용한다.

### 자동 생산은 보조 성장으로 제한

자동 스킬1~16단계의 구매당 초당 효과 후보는 **1·2·4·8·12·18·27·41·62·93·140·210·315·473·710·1,065**다. 이는 스킬 한 개의 효과이며 전체 자동 생산량은 보유 수를 곱해 합산한다. 구매를 반복하면 전체 생산이 다시 커질 수 있으므로 단계 배율만 낮추고 검증을 끝내지 않는다.

동일한10분 접속·동일 구매 정책에서 초당1회 탭하는 플레이의 기본 생산량 중 자동 기여를20~40%로 두는 것을 체감 검토 목표로 제안한다. 부스트·환생·오프라인은 따로 비교한다. 이 비중은 강제 상한이나 동적 감산 공식이 아니며, 실제 보유 수와 구매 경로 시뮬레이션으로 확인할 밸런스 초안이다. 초과하면 자동 효과·구매 가격·해금 간격을 함께 재조정한다. 기존 오프라인8시간·50% 정산 원칙은 유지한다.

탭4단계 해금 누적은10,000→30,000, 자동4단계는20,000→60,000을 후보로 둔다. 5단계 이후는각각30,000×10^(단계−4),60,000×10^(단계−4)로 증가시킨다. 1~3단계 해금은 우선 유지한다. 해금은 누적 획득량이며 현재 잔액을 차감하지 않는다. 현재 기본 가격보다 해금 누적이 높은 것은 의도된 성장 간격이다. 기존유료스킬조기해금은현재코드의기반이며새기능레벨잠금을자동우회한다는뜻이아니다. 신규범위는별도로결정한다.

### 레벨마다 직접 탭하기

**기존 단계별 성장 목표 AND 해당 레벨 구간의 직접 탭 목표**를 충족해야 다음 레벨을 수령하는 안을 제안한다. 성장 목표의 수치는 위 효과 곡선에 맞춰 다시 정한다. 탭만 하고 자산 목표를 건너뛰거나, 자동 생산만으로 여러 단계를 연속 통과하지 않게 한다.

| 올라갈 레벨 | 직전 레벨 진입 후 추가 직접 탭 | 1회/초로 눌렀을 때의 입력 시간 |
| --- | ---: | ---: |
| Lv.2 | 30회 | 30초 |
| Lv.3 | 45회 | 45초 |
| Lv.4 | 68회 | 1분8초 |
| Lv.5 | 102회 | 1분42초 |
| Lv.6 | 153회 | 2분33초 |
| Lv.7 | 230회 | 3분50초 |
| Lv.8 | 345회 | 5분45초 |
| Lv.9 | 518회 | 8분38초 |
| Lv.10 | 777회 | 12분57초 |

사용자 제안을 반영해 첫 목표30회, 이후 `다음 목표 = (직전 목표×3+1) ÷ 2의 정수 몫`으로 정한다. 직전 정수 목표의1.5배를 매번 올림하는 규칙이다. 합계2,268회이며 한 번에 연속으로 누를 필요 없이 여러 접속에 걸쳐 누적한다. 표의 시간은 입력량 환산이며 레벨 도달 예상 시간이 아니다. 빠르게 두드려야 유리한 제한 시간이나 탭 속도 합격 기준은 두지 않는다. 실측 전 밸런스 초안이고 게임 코드에는 적용하지 않았다.

직접 탭은 기존 중앙 생산 영역의 유효한 개별 활성화다. 길게 눌러 자동 반복된 탭·자동 생산·6칸 수확·제작 제스처·결과 수령은 포함하지 않는다. 접근성 클릭·키보드/보조 입력도 동일한 개별 활성화로 인정하며 포인터 터치만 강제하지 않는다. 같은 입력의 중복 콜백은 한 번만 센다. 탭 조건은 레벨 진입 후 누적분이며 이미 한 수십만 탭을 모든 후속 단계에 재사용하지 않는다.

## 플레이 체감 목표와 검증

신규 시작에서는 첫 탭 스킬까지10~30회 안의 직접 입력, 첫 자동 생산 구매까지2~5분의 혼합 플레이를 검토 목표로 둔다. 자동 생산은 접속 사이 진행을 돕고, 적극적으로 누르는 사람은 같은 접속 시간에 다음 구매와 성장에 빨리 도달해야 한다. 이 시간·횟수 역시 실측 전 밸런스 초안이다.

시뮬레이션은 무탭·초당1회·초당2회·짧은 접속과 오프라인 조합을 같은 구매 정책으로 비교한다. 기본/부스트/환생을 나누고, 단계별 도달 시간·필요 탭·직접 생산 비중·첫 구매·자동 구매 시점을 기록한다. 자동만으로 직접 탭 게이트를 통과하지 못하는지, 느린 입력도 누적 진행 가능한지, 후반 목표가 막히지 않는지 확인한다. 기존 테스트의 목표와 골든 허용치를 단순 완화하지 않는다. 기존 시즌 회귀와 신규 난이도 검증을 분리한다. **이번 시뮬레이션·게임 테스트·실기기 검수는 미실행**이다.


## Lv.50 릴리즈와 복합 수급 검증

릴리즈만렙은50이다. 위탭목표는Lv.2~10까지만있는기존밸런스초안이며Lv.11~50을1.5배로외삽하지않는다. 주문종류/수량·기능해금간격·스킬효과/두재화구매비용·IAP/판매황금수급을함께검증해1~50전체곡선을정한다. Lv.10도달은릴리즈완료아님.

만족도는별5개만점,높을수록판매황금드롭확률이증가한다. 확률표/별점계산/수량이결정되기전예상황금수급이나구매소요시간을수치로단정하지않는다. 초기가지고있는황금이없는사용자가기본팥연습/판매와첫구매에접근가능한지검증하고시작보너스/확정드롭을임의추가하지않는다.

정확한기능해금레벨·레시피주기·Lv.11~50요구량/보상·환생정책은미정이다. [경제/해금](10_복합경제와50레벨해금.md)을기준으로재산정한다.

## 하루2회 광고의 수급 영향

IAP/만족도판매희귀와별도로하루최대2회광고황금경로를반영한다. 지급량이결정되지않아일일황금수급/첫구매시간을숫자로단정하지않는다. 미시청/광고실패·판매운이낮은경우와선택시청사용자의1~50성장을비교한다. 광고를필수튜토리얼이나강제시청으로바꾸지않고초기구매막힘을별도검토한다.

## 주문·숙련·영업과 성장

앞의 탭/자동 효과·구매/해금 수치는 기존 밸런스 초안이다. **영업 시작전/종료후 자동생산은없고 영업중만생산**한다. 앱종료후에도영업상태면기존8시간/50%로붕어빵력만정산하며제품수확/재고지급없음. 기존초안시간을새운영게임의확정성장시간으로간주하지않는다.

레벨상승은주문맛종류·수량증가와연결한다. 손님별제한시간·줄대기소모·즉석제작시간으로재고준비가유리하되재고는5영업일후소멸해과잉생산을억제한다. 레벨별주문표·최대방문·특정익힘등장시점·초기시간추가차감은미정이다. 힐링목표에맞는피로도/성공률을실측하며새제한시간/수량/페널티를만들지않는다.

레시피는간헐상점/미션획득이며연습량은맛별로다르다. 이연습량은레벨직접탭목표와별도다. 보유레시피의연습/즉석판매를레벨탭미충족이나숙련미완료로막지않는다. 실패/주문용제작의연습인정과5단계도감의숙련관계는미정이다. 해당맛도감완성/6구해금은모든숙련조건을충족할때만이루어진다.
