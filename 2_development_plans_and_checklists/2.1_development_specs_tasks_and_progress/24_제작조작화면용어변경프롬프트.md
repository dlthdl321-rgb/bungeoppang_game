# 24. 제작 조작·화면·용어 변경 단계별 프롬프트

작성 2026-11-16. 사용자가 요청한 제작 조작(짤주머니 색칠, 원 그려 뒤집기), 화면 배치(6구 폭, 매대 높이, 영업 상태별 두 틀), 용어 변경을 순서대로 나눈 작업 지시문이다. 각 단계의 프롬프트를 새 Claude Code 세션에 그대로 붙여 넣는다. 한 단계가 완료 기준을 통과한 뒤 다음 단계로 넘어간다.

## 사용자 요청 원문 (2026-11-16)

- 조작 1. 짤주머니로 반죽이나 속을 짤 때 붕어빵 틀에 색칠하듯이 드래그한다.
- 조작 2. 틀을 뒤집을 때 한 바퀴 원을 그리는 동작을 한다.
- 화면 1. 하단 6구 틀 이미지를 화면 폭에 맞춰 키운다.
- 화면 2. 매대 높이를 왼쪽 빨간 체크 행주 높이까지만 보이게 한다.
- 화면 3. 영업 준비 중에는 6구 틀이 활성화되지 않고 빈 틀로 보인다.
- 화면 4. 큰 틀은 영업 중에는 틀 없이 큰 붕어빵만 있어 클리커 기능만, 영업 준비 중에는 틀이 있고 타이쿤(제작) 기능만 있다.
- 내용 1. 용어 변경: 큰 틀 제작 → 스페셜 붕어빵 제작, 6구 제작 → 숙련된 붕어빵 제작.

```text
CLAUDE.md, MASTER.md(1077~1083행과 1단계에서 새로 쓴 결정 절), 00_결정취합.md의 2026-11-16 절,

  틀 밖으로 나간 선은 양에 넣지 않는다.
```

## 사용 팁

- 단계마다 새 세션을 연다. 앞 단계 결과는 이 문서와 MASTER.md에 남기므로 대화 기록이 없어도 이어진다.
- 각 단계가 끝나면 이 문서의 해당 단계 아래에 "**N단계 결과 (날짜, 커밋)**" 표를 붙여 달라고 요청한다.
- 1단계 결정 전에는 3·5·6단계를 시작하지 않는다. 2단계(용어)는 1단계 직후 바로 해도 된다.
- 5단계는 판정 공식과 서버까지 바뀌므로 "설계 보고 → 내 확인 → 구현" 순서를 지키게 한다.
- 이 작업은 게임 조작과 화면을 바꾸므로 23번 9단계(실기기 검수와 내부 테스트 업로드)보다 먼저 끝낸다.
- 완료 보고 때 실제로 실행한 명령과 결과(테스트 수)를 보여 달라고 요구한다.
