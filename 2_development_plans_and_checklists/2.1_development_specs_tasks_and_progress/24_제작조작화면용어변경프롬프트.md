# 24. 제작 조작·화면·용어 변경 단계별 프롬프트

작성 2026-11-16. 사용자가 요청한 제작 조작(짤주머니 색칠, 원 그려 뒤집기), 화면 배치(6구 폭, 매대 높이, 영업 상태별 두 틀), 용어 변경을 순서대로 나눈 작업 지시문이다. 각 단계의 프롬프트를 새 Claude Code 세션에 그대로 붙여 넣는다. 한 단계가 완료 기준을 통과한 뒤 다음 단계로 넘어간다.

## 사용자 요청 원문 (2026-11-16)

- 조작 1. 짤주머니로 반죽이나 속을 짤 때 붕어빵 틀에 색칠하듯이 드래그한다.
- 조작 2. 틀을 뒤집을 때 한 바퀴 원을 그리는 동작을 한다.
- 화면 1. 하단 6구 틀 이미지를 화면 폭에 맞춰 키운다.
- 화면 2. 매대 높이를 왼쪽 빨간 체크 행주 높이까지만 보이게 한다.
- 화면 3. 영업 준비 중에는 6구 틀이 활성화되지 않고 빈 틀로 보인다.
- 화면 4. 큰 틀은 영업 중에는 틀 없이 큰 붕어빵만 있어 클리커 기능만, 영업 준비 중에는 틀이 있고 타이쿤(제작) 기능만 있다.
- 내용 1. 용어 변경: 큰 틀 제작 → 스페셜 붕어빵 제작, 6구 제작 → 숙련된 붕어빵 제작.

## 5단계 — 짤주머니 드래그 색칠

```text
CLAUDE.md, MASTER.md(1077~1083행과 1단계에서 새로 쓴 결정 절), 00_결정취합.md의 2026-11-16 절,

lib/ui/workshop_mold_stage.dart, lib/cooking_session.dart, lib/cooking_result_rules.dart,
lib/workshop_controller.dart(580~660행), config/development_balance.json의 manual_cooking과
맛별 숙련 행, tools/development_balance.py, firebase/functions의 검증 코드를 읽어라.

목표: 첫 반죽·속·둘째 반죽 세 단계를 길게 누르기 대신 틀 위를 색칠하듯 드래그하는 조작으로 바꾼다.

규칙:
- 붕어빵 모양 마스크(WorkshopMoldArt.fishRect와 틀 그림의 공동 모양) 위를 칠한 면적 비율이 양이다.
  반죽은 크림색, 속은 맛 색으로 칠한 자리가 바로 보인다. 짤주머니 그림은 손가락을 따라간다.
- 붓 굵기·목표 비율·넘침 기준·덧칠 처리는 1단계 결정대로, 모두 manual_cooking 설정값으로 둔다.
- 포인터 하나만 인정. 손을 떼면 그 단계를 확정. 취소·일시정지 시 확정하지 않는다.
  틀 밖으로 나간 선은 양에 넣지 않는다.
- 기울기 센서는 1단계 결정대로 처리한다.

할 일:
1. 먼저 설계를 보고한다: 면적 계산 방식(격자 샘플링 등, 성능 기준 60fps), 세션에 저장할 값
   (예: firstBatterMs → 면적 permille), 저장 형식 변경 여부와 이전 방법, 서버 검증
   (receivedMs 검사, generated balance)이 받는 값의 변화. 내 확인 후 구현한다.
2. 면적 계산을 화면과 분리된 순수 함수로 만들고 단위 테스트(빈 틀 0%, 꽉 칠함 100%, 틀 밖 무시,
   덧칠·넘침)를 붙인다.
3. 품질 판정(cooking_result_rules.dart)과 컨트롤러 단계 검사를 새 값으로 옮긴다. 시간 기준 설정
   (batter_target_ms, filling_capacity_ms)을 바꾸거나 지우면 development_balance.py 검사, 생성 코드,
   firebase/functions 생성본과 서버 테스트를 함께 갱신한다.
4. 양 표시 글: 칠하는 중 '속 양 72% · 손을 떼면 마무리', 대기 '틀 위를 문질러 속을 짜 주세요',
   반죽은 '틀 위를 문질러 반죽을 부어 주세요'.
5. 설정의 '모션 줄이기'·진동 설정과 맞는지 확인한다.
6. 위젯 테스트로 드래그 → 손 뗌 → 다음 단계, 취소, 두 번째 손가락 무시를 확인한다.
   제작 중 골든(workshop_home_baking_390x844)을 다시 만든다.
7. MASTER의 짤주머니 절, 설정값 표, 저장 형식 절을 고친다.

완료 기준: 세 단계 모두 드래그로 진행, 단위·위젯·서버 테스트 통과, MASTER 반영 체크리스트 보고.
```

## 6단계 — 원 그려 뒤집기

```text

- '모션 줄이기'가 켜져 있으면 회전 연출을 줄인다(판정은 같게).
- 안내 글 예: '틀 둘레로 원을 한 바퀴 그려 뒤집어요'. 튜토리얼 5단계 문구도 맞춘다.

할 일:
1. 각도 누적 계산을 순수 함수로 만들고 단위 테스트(한 바퀴 성공, 반 바퀴 부족, 중심에서 맴돌기 무시,
   방향 바꾸기, 취소).
2. 위젯 테스트로 원 그리기 → cooking 진입.
3. MASTER 조작 절과 설정값 표를 고친다.

완료 기준: 탭으로는 뒤집히지 않고 원을 그리면 뒤집힘, 테스트 통과.
```

## 사용 팁

- 단계마다 새 세션을 연다. 앞 단계 결과는 이 문서와 MASTER.md에 남기므로 대화 기록이 없어도 이어진다.
