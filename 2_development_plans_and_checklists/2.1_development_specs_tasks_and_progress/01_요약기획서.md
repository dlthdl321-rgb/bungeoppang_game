## 최신 확정 반영 — 2026-10-16

10월 15일 [사용자 답변 기록](2.1.1_game_rules_and_decisions/00_결정취합.md)의 첫~세 번째 답변이 이전 미정/추천 문장보다 우선한다. 팥 미디엄 레시피만 기본 지급하고 구매 없이 핵심 진입한다. 다른 익힘은 직접 만들어 수집하며 해당 익힘의 선구매를 요구하지 않는다. 숙련은 맛별이고 **연습5종 수집 AND 인정 연습량 AND 손기술 통과량**을 모두 요구한다. 저장 확정된 실패 완주 연습은 연습량에 포함, 주문 제작은 수집만 인정한다. 초기 숙련/6구/도감완성을 선지급하지 않는다. 덜 익음은 특별 주문 판매 가능이며, 6구 수확/제품 보관은 여전히 다음 질문 대기다. 최종 단계 명칭·미디엄 대응·손기술 세부 기준·횟수·가격·확률·광고량은 새로 확정하지 않는다.

[선행 작업별 대조와 복구 설계](12_선행기획검토와복구설계.md)를 함께 읽는다. 아래 구형 설명에서 실패 인정·주문 반영·5종 관계를 통째로 미정이라고 표현한 부분은 이 확정 범위로 한정해 읽는다. 코드/데이터 이전·실행 검수는 하지 않았다.

## 핵심 순환과 주문 대응

**레시피 획득 → 큰 틀에서 맛별 연습 → 숙련 조건 충족·해당 도감 완성 → 6구 해금 → 직접 수확·재고 확보 → 손님 주문 대응·취향 수집**.

주문은 미리 준비한 재고를 제공하거나 큰 틀에서 즉석 제작해 판매한다. 즉석 제작은 숙련 전후 모두 가능하지만 제작 중에도 손님 대기시간이 흐른다. 줄의 뒤 손님도 기다리는 동안 개인 시간이 줄어들어 재고가 유리하다. 뒤 순서라는 이유로 초기시간까지 추가 차감할지는 미정이다.

큰 틀의 기본 조작은 **종류 선택 → 첫 반죽 → 짤주머니를 길게 눌러 속 양 조절 → 둘째 반죽 → 닫기 → 뒤집기 → 굽기 → 터치 꺼내기 → 결과**다. 센서 없는 환경은 터치 대체로 진행한다. 맛별 연습 방식은 달라지며 한 번 성공했다고 숙련·도감을 완료하지 않는다.

## 도감·재고·재화의 구분

| 구분 | 관리하는 내용 |
| --- | --- |
| 붕어빵 도감 | 맛마다 익힘5단계. 발견·연습 진행·정식 완성을 구분. 임시 명칭은 덜 익은/부드럽게 익은/노릇하게 익은/바삭하게 익은/타버린 |
| 손님 도감 | 이름·외형·특성, 좋아하는 맛·익힘, 취향 발견 진행. 현재 주문과 별도로 유지 |
| 리얼 붕어빵 재고 | 맛×익힘×제작 영업일별 묶음과 수량. 판매/소멸과 영구 도감 기록을 구분 |
| 붕어빵력 | 영업 생산 재화. 상점/스킬 구매 때 황금붕어빵력과 함께 사용. 잔액과 누적 구분 |
| 황금붕어빵력 | IAP충전·판매완료희귀보상·하루최대2회선택형광고보상. 판매 만족도는별5개 만점,높을수록드롭확률증가. 상품·지갑 유지 |

코인·별·기존 소유권은 보존한다. 상점 상품/스킬은 **두 재화를 함께 지불**하고 항목마다 두 비용이 다르다. 각 금액·일반 판매 대금·희귀 보상 확률/지급량은 미정이다. 별5개도 황금 보상 확정 지급을 뜻하지 않는다.

## 영업·오프라인·난이도

‘영업 시작’을 접속과 구분한다. **영업 중에만 붕어빵력이 자동 생산되며 앱을 꺼도 영업 상태는 유지**된다. 복귀 시 기존 오프라인 최대8시간·50% 규칙으로 미정산 시간만 반영한다. 시작 전/종료 후에는 자동 생산하지 않고 재고 자동 수확·오프라인 제품 지급은 없다.

재고는 현실 공백 날짜로 노화하지 않는다. 월요일 제작→화요일 영업=1일→미접속 후 토요일 영업=2일이다. 같은 날짜 여러 번 영업해도 중복 노화하지 않는다. 영업일 경계시각·다음 날짜 복귀 처리·영업 종료 방법은 미정이다.

초반 주문은 적은 종류/수량, 성장 후에는 여러 맛/많은 수량을 요구한다. 손님별 대기시간과 동시 방문이 난이도를 만든다. 기존 직접 탭 목표 **30→45→68→102→153→230→345→518→777회**, 자동 효과 완화안은 **밸런스 초안**으로 유지하며 새로운 주문 난이도와 함께 검증한다. 새 주문 수량·제한시간·연습 횟수는 정하지 않았다.

## 황금붕어빵력 광고 보상

플레이어가선택해광고를시청하면 **하루최대2회** 황금붕어빵력을받을수있다. 강제광고는추가하지않는다. 회당지급량·업체/SDK·광고해금/노출위치·일일경계는미정이다. 실패/중도종료는보상완료가아니며중복콜백/재접속으로재지급하지않는다. 일일광고한도는재고노화영업일과구분한다. [광고상세](11_하루2회보상형광고.md)에일일제한·지갑검증·기존광고금지원칙예외를정리했다.

## 만렙50과 기능 해금

**첫 릴리즈는Lv.50까지** 성장하도록 만든다. 처음 제공되는 꾸미기는 **아바타 꾸미기만**이며 나머지 꾸미기 분류·도감·친구는 일정 레벨에서 열린다. 정확한 해금 레벨/순서는 미정이다. 기능 잠금·아이템 소유/구매·레시피 숙련은 서로 구분하고 큰틀 기본연습과 숙련 전 즉석 판매를막지 않는다.

기존30회×1.5 탭 표는Lv.2~10 초안이며 Lv.50까지연장하지 않는다. 1~50 성장·주문·기능·두 재화 가격·황금 희귀 수급을함께 조정한다. 시작 황금 지급·무료 구매·확정 드롭은임의 추가하지 않는다. [경제·해금 상세](10_복합경제와50레벨해금.md)에복구/이전과 미정 항목을정리했다.

## 손님·관계 기획 반영 — 2026-10-16

손님을 무작위 주문 역할에서 반복 방문하는 이웃 8명으로 확장한다. 윤하·도윤·막례·서진·태오·은채·민재·수아는 각기 다른 외모·호칭·주문 반응·관계 변화를 가진다. 도윤의 가방은 노란색이며, 수아의 표시 명칭과 서진의 개인 호칭은 해당 이벤트를 완료한 뒤에만 바뀐다.

주문 경험으로 취향을 발견하고 친밀도 4단계에 따라 개인 사연·관계 이벤트·드문 선택 대화와 다음 방문 후일담을 연다. 선택은 A/B/C 또는 미소 배웅이며 어떤 선택도 친밀도를 깎거나 기본 관계 이벤트를 막지 않는다. SNS·실제 촬영·무료 상품·추가 황금 지급 기능은 추가하지 않는다. 상세 대사와 8개 선택 사건은 [21_손님캐릭터와관계시스템](21_손님캐릭터와관계시스템.md)에 보존했다. 현재 코드의 임시 손님 8종과 이 콘텐츠의 구현은 별개다.
