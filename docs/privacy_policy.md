# 오늘의 붕어빵 개인정보처리방침

시행일: 2026-10-05

'오늘의 붕어빵'(이하 "앱")은 무료이며 광고가 없는 오프라인 게임입니다. 이 방침은 앱이 어떤 정보를 어디에 저장하는지 설명합니다.

## 1. 개발자가 수집하는 개인정보

**없습니다.** 앱은 이름, 이메일, 전화번호, 연락처, 위치, 기기 식별자, 광고 ID를 요청하거나 읽지 않습니다. 개발자나 제3자의 서버로 정보를 보내지도 않습니다. 배포용 앱에는 인터넷 권한이 없으며 회원가입·로그인 기능도 없습니다.

앱에는 광고, 인앱결제, 분석, 오류 수집 SDK가 포함되어 있지 않습니다.

## 2. 기기에만 저장되는 정보

게임을 이어서 하기 위해 아래 정보를 사용자의 기기 안 앱 전용 저장소(SQLite)에만 저장합니다.

- 게임 진행: 재화, 코인, 스킬, 레벨과 레벨 도달 시각, 미션 진행, 아이템, 꾸미기, 설정, 저장 시각
- 내 기록: 최고 초당 생산, 누적 굽기 횟수, 플레이한 날짜 수, 최고 콤보, 하루 최고 생산
- 주간 도전·업적: 이번 주 진행과 수령 여부, 달성한 업적과 고른 칭호

내 기록은 이 기기에서 한 플레이만 담으며 다른 사람의 기록과 비교하거나 어디에도 보내지 않습니다. 이 정보는 기기 밖으로 전송되지 않으며 개발자가 볼 수 없습니다.

이전 버전에서 만든 친구 초대 시험 기록(무작위 가상 ID·추천 코드)이 있다면 저장 파일에 그대로 남아 있지만, 배포용 앱에서는 사용하거나 표시하지 않습니다.

## 3. 사용자가 직접 하는 공유와 복사

'게임 공유' 화면에서 사용자가 '공유하기'나 '문구 복사하기'를 누르면 게임 소개 문구와 Google Play 스토어 링크가 Android 공유 창으로 열리거나 클립보드에 복사됩니다. 문구에는 게임 진행, 기기 정보, 추천 코드 같은 개인 식별 정보가 들어가지 않습니다. 어떤 앱으로 누구에게 보낼지는 사용자가 직접 선택합니다. 앱이 자동으로 보내는 내용은 없으며 공유해도 게임 보상은 없습니다. 보낸 뒤의 정보는 사용자가 선택한 앱의 개인정보처리방침을 따릅니다.

## 4. 보관 기간과 삭제

정보는 사용자가 앱을 삭제하거나 Android 설정에서 앱 데이터를 지울 때까지 기기에 남습니다. 앱을 삭제하거나 데이터를 지우면 모든 진행 기록이 사라지며 복구할 수 없습니다. 개발자는 서버에 사본을 두지 않으므로 대신 삭제하거나 복구할 수 없습니다.

## 5. 제3자 제공

개발자가 수집하는 정보가 없으므로 제3자에게 제공하는 정보도 없습니다.

## 6. 아동

앱은 연령과 관계없이 개인정보를 수집하지 않습니다.

## 7. 방침 변경

앱 기능이 바뀌어 정보 처리 방식이 달라지면 이 문서를 고치고 시행일을 갱신합니다.
