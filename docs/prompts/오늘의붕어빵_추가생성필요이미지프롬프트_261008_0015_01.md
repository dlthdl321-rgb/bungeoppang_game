1차 세트를 게임에 넣으면서 **그림이 없거나 쓸 수 없는 것**만 모았습니다. 프롬프트는 이미지 생성 도구에 그대로 붙여 넣을 수 있게 영어로 썼습니다. 남자 사장님 그림에는 1차 세트와 같은 속눈썹 문구를 넣었습니다.

## 공통 규칙

- 저장 위치: `이미지/추가 생성 이미지 2/` 아래에 1차 세트와 같은 폴더 구조와 아래 파일 이름으로 저장합니다.
- 흰 단색 배경을 씁니다. 바닥 그림자, 테두리, 글자, 워터마크는 넣지 않습니다.
- 물체 전체가 화면 안에 들어오고 **네 변 모두 여백**이 있어야 합니다. 잘린 그림은 쓸 수 없습니다.
- 같은 묶음은 **첫 장을 먼저 만들고, 나머지는 그 그림을 참조한 수정(edit)** 으로 만듭니다. 위치와 크기가 같아야 겹쳐 쓸 수 있습니다.

**스타일 문장**: 1~5절 프롬프트의 `<STYLE>` 자리에 넣습니다. 1차 세트와 같은 문장입니다.

```

```
