# 오늘의 붕어빵 — 처음 시작하는 사장님을 위한 가이드

> 골목 노점에서 붕어빵을 굽고, 가게를 키우고, 사장님과 노점을 꾸미는 게임이에요.
> 이 가이드는 처음 하는 분이 **첫 10분 → 첫날 → 그 이후** 순서로 따라 할 수 있게 정리했어요.

---

## 1. 한눈에 보는 게임 흐름

```
붕어빵 굽기(탭) ──> 붕어빵 모으기 ──> 스킬 사기 ──> 더 빨리 굽기
        │                                         │
        └──── 미션 달성 ──> 코인 받기 ──> 꾸미기·부스트 ┘
                     │
                     └──> 레벨업 ──> Lv.10 ──> 새 노점 열기(명성 별)
```

- **붕어빵**: 굽기로 모으는 기본 재화예요. 스킬을 살 때 써요.
- **코인**: 미션·업적·레벨업 보상으로 받아요. 꾸미기를 살 때 써요.
- **황금 붕어빵**: 상점 '충전' 탭에서 사는 유료 재화예요. 없어도 게임을 끝까지 할 수 있어요.

---

## 2. 처음 켰을 때

1. 첫 화면에 **"붕어빵을 눌러 굽고, 스킬에서 강화해요."** 안내가 나와요. **시작하기**를 누르세요.
2. 가운데 큰 붕어빵의 **'터치해서 굽기'** 를 눌러 보세요. 누를 때마다 붕어빵이 1개씩 쌓여요.
3. 붕어빵 **10개**를 모으면 첫 레벨 미션이 끝나요. 왼쪽 위 **Lv 배지**를 눌러 보상을 받으세요.

---

## 3. 홈 화면 살펴보기

| 위치 | 이름 | 하는 일 |
| --- | --- | --- |
| 왼쪽 위 | **Lv 배지 · 경험치 바** | 지금 레벨과 미션 진행률. 누르면 **레벨 미션** 화면이 열려요 |
| 위 가운데 | **보유 붕어빵** | 지금 가진 붕어빵과 누적 생산량 |
| 위 오른쪽 | **클릭당 / 초당** | 한 번 누를 때 굽는 양, 가만히 있어도 1초마다 굽는 양 |
| 오른쪽 위 | **설정(톱니)** | 소리·진동·길게 눌러 굽기·모션 줄이기 |
| 가운데 | **큰 붕어빵** | 누르면 구워져요. 빠르게 연타하면 **콤보**가 쌓여요 |
| 아래 | **붕어빵 틀** | 가끔 붕어빵 하나가 **황금빛**으로 반짝여요 (→ 6장 황금 찬스) |
| 오른쪽 아래 | **조리 창** | 사장님이 붕어빵을 굽는 모습. 꾸민 옷이 그대로 보여요 |
| 맨 아래 | **메뉴 / 스킬 / 꾸미기 / 상점** | 주요 화면으로 가는 버튼 |

> 💡 숫자가 커지면 **만·억·조·경…** 단위로 짧게 표시돼요.

## 4. 붕어빵 굽기

### 탭해서 굽기
- 큰 붕어빵을 누르면 **클릭당** 수치만큼 붕어빵이 생겨요.
- **1초 안에** 계속 누르면 콤보가 이어져요. 20콤보, 50콤보에서 색이 바뀌어요.
- 콤보는 기록과 업적(50 콤보 → 칭호 '번개손'), 랭킹에 쓰여요. 생산량을 늘려 주지는 않아요.

### 길게 눌러 굽기
- 설정에서 **길게 눌러 굽기**를 켜면, 붕어빵을 누르고 있는 동안 **1초에 4번** 자동으로 구워요.
- 손가락이 편해지지만 콤보는 쌓이지 않아요.

### 자동 생산
- 스킬 중 **자동 생산** 스킬을 사면 아무것도 안 해도 **초당** 수치만큼 붕어빵이 쌓여요.
- 게임 후반에는 자동 생산이 주된 수입이 돼요.

### 자리를 비웠을 때
- 앱을 닫아 두어도 자동 생산의 **50%** 를 모아 둬요. 최대 **8시간**까지 쌓여요.
- 하루 이상 비웠다가 오면 **"다시 오셨네요!"** 화면에서 그동안 모인 양을 보여 줘요.

---

## 5. 스킬 — 더 빨리 굽기

하단 **스킬** 버튼을 누르세요. 스킬은 두 종류이고, 각각 16단계가 있어요.

| 종류 | 효과 | 첫 스킬 |
| --- | --- | --- |
| **클릭 생산** | 한 번 누를 때 굽는 양 증가 | 반짝이는 틀 (붕어빵 15개) |
| **자동 생산** | 1초마다 저절로 굽는 양 증가 | 작은 화로 (붕어빵 50개) |

- 같은 스킬을 여러 번 살 수 있어요. 살 때마다 가격이 조금씩 올라요.
- **1개 / 10개 / 최대** 중에서 골라 한 번에 살 수 있어요.
- 사기 전에 **현재 효과 → 구매 후 효과**를 보여 줘요.
- 다음 단계 스킬은 **누적 생산**이 일정량을 넘으면 열려요. (예: 작은 화로 다음 '부지런한 집게'는 누적 1,000개)

> 💡 **초반 요령**: 처음에는 클릭 스킬 '반짝이는 틀'을 1~2개 산 뒤, 바로 자동 스킬 '작은 화로'를 사세요.
> Lv.3 미션이 **초당 생산 1개**라서 자동 생산이 꼭 필요해요.

---

## 6. 부스트 — 잠깐 동안 생산 몇 배

부스트가 켜지면 정해진 시간 동안 **클릭·자동 생산이 모두 몇 배**가 돼요. 가운데 붕어빵이 황금색으로 바뀌고 남은 시간이 표시돼요.

| 부스트 | 얻는 방법 | 효과 |
| --- | --- | --- |
| **황금 찬스** | 플레이 중 3~7분마다 틀 위 붕어빵이 **8초 동안** 황금빛으로 반짝여요. 그때 누르세요 | 1분 동안 ×3 |
| **친구 방문** | 친구가 하루 한 번 내 가게에 들러요 | 5분 동안 ×3 |
| **초대 손님** | 나를 초대한 친구가, 내가 Lv.1을 달성하면 손님으로 와요 | 10분 동안 ×5 |
| **황금 부스트** | 상점에서 황금 붕어빵 20개로 사요 | 10분 동안 ×3 |

- 종류가 다른 부스트가 겹치면 **가장 큰 배율 하나만** 적용돼요.
- 같은 부스트가 또 생기면 시간이 늘어나요.
- 앱을 닫아도 부스트 시간은 흘러가요.

> 💡 Lv.4 미션이 **'황금 찬스 잡기'** 예요. 틀을 가끔 살펴보세요!

---

## 7. 레벨 미션 — 게임의 큰 목표

왼쪽 위 **Lv 배지**나 **메뉴 → 레벨 미션**에서 열어요.
조건을 모두 채운 뒤 **보상 받기**를 눌러야 레벨이 올라가요. 레벨업마다 **코인 3개**를 받고, 새 꾸미기가 열려요.

| 레벨 | 미션 |
| --- | --- |
| Lv.2 | 굽기 안내 확인 · 누적 붕어빵 10개 |
| Lv.3 | 초당 생산 1개 |
| Lv.4 | 황금 찬스 1번 잡기 |
| Lv.5 | 초당 생산 5,000개 · 기본 외 꾸미기 1개 보유 |
| Lv.6 | 초당 생산 4억 개 |
| Lv.7 | 초당 생산 160억 개 · 부스트 누적 5번 사용 |
| Lv.8 | 초당 생산 8,000억 개 |
| Lv.9 | 초당 생산 5조 개 · '성운 공방' 스킬 보유 |
| Lv.10 | 초당 생산 20조 개 · 업적 12개 달성 |

- **초당 생산** 조건은 부스트를 뺀 기본 수치로 판정해요. 스킬로 올려야 해요.
- 화면 아래에서 **다음 단계 미리보기**를 볼 수 있어요.
- 하루 2~3번, 10분 정도씩 하면 Lv.5는 첫날, Lv.10은 3주쯤 걸려요.

## 8. 매일·매주 할 일

### 일일 미션 (메뉴 → 일일 미션)
매일 **한국 시각 자정**에 새로 시작해요. 받지 않은 보상은 자정에 사라져요.

| 미션 | 목표 | 보상 |
| --- | --- | --- |
| 붕어빵 탭 | 50번 | 코인 2 |
| 오늘 붕어빵 생산 | 1,000개 | 코인 3 |
| 스킬 구매 수량 | 3개 | 코인 2 |
| 기본 초당 생산 | 10개 | 코인 3 |
| **전체 완료 보상** | 위 4개 모두 | **코인 10** |

하루에 코인을 최대 **20개** 모을 수 있어요.

### 주간 도전 (메뉴 → 주간 도전)
매주 **월요일 0시(한국 시각)** 에 새로 시작해요. 계절마다 제목이 바뀌어요(벚꽃·여름밤·단풍 골목·첫눈).

| 도전 | 보상 |
| --- | --- |
| 탭으로 1,000번 굽기 | 코인 3 |
| 3일 동안 노점 열기 | 코인 3 |
| 스킬 20개 구매 | 코인 3 |
| 일일 미션 전체 완료 3회 | 코인 7 |

## 9. 꾸미기 — 사장님과 노점 꾸미기

하단 **꾸미기** 버튼을 누르세요. 탭이 다섯 개 있어요.

| 탭 | 꾸미는 것 |
| --- | --- |
| **헤어** | 머리 모양 |
| **의상** | 상의·하의·신발·앞치마 |
| **소품** | 모자·액세서리·도구 |
| **붕어빵** | 붕어빵 무늬·토핑 |
| **가게** | 배경(날씨·계절)·화로·장식·등불 색 |

- 항목을 고르면 **미리보기**만 바뀌어요. 마음에 들면 **적용**을 눌러 사고 장착해요.
- 한 번 산 꾸미기는 **영구 보유**예요. 다시 장착할 때는 무료예요.
- 일부 항목은 **레벨**이 올라야 열려요.
- 꾸미기는 **모습만** 바꿔요. 생산량에는 영향이 없어요.
- 코인 대신 **황금 붕어빵**(코인 가격 × 5)으로도 살 수 있어요. 이때는 레벨 잠금 없이 바로 살 수 있어요.

> 💡 Lv.5 미션에 **'기본 외 꾸미기 1개'** 가 있어요. 그 전에 코인으로 싼 꾸미기 하나를 사 두세요.

## 10. 상점

하단 **상점** 버튼을 누르세요.

| 탭 | 내용 |
| --- | --- |
| **장비** | 화로(붕어빵 틀)·집게 같은 도구 꾸미기 |
| **꾸미기** | 사장님·붕어빵 꾸미기 |
| **테마** | 배경·장식·등불 같은 가게 꾸미기 |
| **충전** | 황금 붕어빵 구매 (Google Play 결제) |

상점에서 산 꾸미기는 바로 장착돼요. 상점 안에서 **코인 · 부스트 보기**로 부스트 화면도 열 수 있어요.

**황금 붕어빵으로 할 수 있는 것**
- 꾸미기를 레벨 잠금 없이 사기
- 아직 안 열린 스킬을 **먼저 해금**하기 (해금 후 구매는 붕어빵으로)
- 황금 부스트(10분 ×3) 사기

> 황금 붕어빵은 로그인한 카카오 계정에 보관돼요. 다시 설치해도 꾸미기와 스킬 해금은 돌아오지만, 이미 쓴 부스트는 돌아오지 않아요.

## 11. 메뉴 화면

하단 **메뉴** 버튼을 누르면 아래 항목이 나와요.

| 항목 | 내용 |
| --- | --- |
| **도감** | 모은 꾸미기와 칭호 |
| **업적** | 업적 20개. 달성하면 코인이나 **칭호**를 받아요 |
| **통계** | 내 기록, 온라인 랭킹 |
| **배경 테마** | 가게 꾸미기 바로 가기 |
| **일일 미션** | 8장 참고 |
| **주간 도전** | 8장 참고. 남은 시간 표시 |
| **레벨 미션** | 7장 참고 |
| **친구** | 친구 추가·방문 (12장) |
| **공유** | 친구에게 게임 소개 문구와 링크 보내기 (보상 없음) |

### 업적과 칭호
- 업적을 달성하면 업적 화면에서 직접 **받기**를 눌러요.
- 칭호 업적 예: 1조 개 생산 → '조 단위 제빵사', 50 콤보 → '번개손', Lv.10 → '골목 명장', 꾸미기 전부 수집 → '수집가', 새 노점 첫 개업 → '노점 개척자'
- 받은 칭호 하나를 골라 홈과 기록 화면에 달 수 있어요.

### 통계 (내 기록)
- 최고 초당 생산, 누적 생산·굽기, 플레이 일수, 최고 콤보, 레벨 도달 시각을 보여 줘요.
- 오늘 기록과 지난 최고 기록을 비교하고, 넘으면 **신기록!** 을 표시해요.
- **온라인 랭킹**: 메뉴 → **온라인 랭킹**에서 카카오 계정으로 로그인하면 최고 초당 생산·누적 생산·최고 콤보 순위를 다른 플레이어와 겨뤄요. 탭마다 상위 100명이 보이고, 맨 아래에 내 순위가 늘 보여요. 로그인하지 않아도 게임은 모두 할 수 있어요.

## 12. 친구와 함께

메뉴 → **친구**에서 열어요. 카카오 계정 로그인이 필요해요. 로그아웃은 친구나 온라인 랭킹 화면 위쪽의 **로그아웃** 버튼으로 해요.

- **내 아이디**: 'BB'로 시작하는 10자리예요. **아이디 복사**로 친구에게 보내세요.
- **친구 추가**: 친구 아이디를 입력하면 서로 친구가 돼요.
- **방문하기**: 친구마다 **하루 한 번** 방문할 수 있어요. 방문받은 친구는 **친구 방문 부스트(5분 ×3)** 를 받아요. 서로 방문하면 둘 다 받아요.
- **초대받았나요?**: 초대한 친구의 아이디를 입력하고 Lv.1을 달성하면, 그 친구가 손님으로 와서 **초대 손님 부스트(10분 ×5)** 를 줘요.

> 온라인 기능이 아직 준비되지 않은 버전에서는 "준비 중"으로 표시돼요.

---

## 13. Lv.10 이후 — 새 노점 열기

Lv.10을 달성하면 레벨 미션 화면에 **새 노점 열기**가 나타나요.

- **초기화되는 것**: 보유 붕어빵, 스킬, 레벨(Lv.1로)
- **그대로 남는 것**: 코인, 꾸미기, 업적, 칭호, 기록, 누적 생산
- 대신 **명성 별**을 받아요. 별 1개마다 생산이 **영구히 +5%** 돼요.
- 별은 **전체 누적 생산**이 많을수록 늘어나요. 버튼에 '지금 열면 별 +N'이 미리 표시돼요.
- 다시 오르는 레벨에서는 레벨업 코인을 다시 주지 않아요.

> 💡 별이 1~2개만 늘 때보다, 누적 생산을 더 쌓아 별을 많이 받을 수 있을 때 여는 편이 좋아요.

## 14. 설정

오른쪽 위 **톱니** 버튼을 누르세요.

| 항목 | 내용 |
| --- | --- |
| 배경음 / 효과음 | 켜기·끄기, 음량 조절 |
| 진동 | 켜기·끄기 |
| 길게 눌러 굽기 | 누르고 있으면 1초에 4번 굽기 |
| 모션 줄이기 | 파티클·흔들림·색종이 효과 끄기 |
| 데이터 초기화 | 모든 진행 삭제. **되돌릴 수 없어요** |

게임은 10초마다, 그리고 구매·보상 수령 같은 중요한 순간마다 자동으로 저장돼요.

## 15. 초보 사장님 체크리스트

**첫 10분**
- [ ] 붕어빵 10개 굽고 Lv.2 보상 받기
- [ ] 클릭 스킬 '반짝이는 틀' 사기
- [ ] 자동 스킬 '작은 화로' 사서 Lv.3 달성
- [ ] 틀 위 황금 붕어빵 잡아서 Lv.4 달성

**첫날**
- [ ] 일일 미션 4개 + 전체 완료 보상 받기 (코인 20)
- [ ] 코인으로 꾸미기 1개 사기 (Lv.5 조건)
- [ ] 자동 생산 스킬 위주로 사서 초당 5,000개 → Lv.5
- [ ] 업적 화면에서 받을 보상 확인하기

**그 이후**
- [ ] 하루 한 번 접속해 일일 미션 챙기기 (자리 비운 동안 최대 8시간치 생산)
- [ ] 월요일마다 주간 도전 확인하기
- [ ] 친구 추가하고 매일 서로 방문하기
- [ ] Lv.10 달성 후 새 노점 열기로 명성 별 모으기

## 자주 묻는 질문

**Q. 레벨 조건을 다 채웠는데 레벨이 안 올라요.**
A. 레벨 미션 화면에서 **보상 받기**를 직접 눌러야 레벨이 올라요.

**Q. 부스트 중인데 초당 생산 미션이 안 채워져요.**
A. 레벨·일일 미션의 초당 생산은 부스트를 뺀 기본 수치로 판정해요. 스킬을 더 사세요.

**Q. 일일 미션 보상이 사라졌어요.**
A. 받지 않은 보상은 자정(한국 시각)에 사라져요. 주간 도전은 월요일 0시에 사라져요.

**Q. 꾸미기를 사면 생산이 늘어나나요?**
A. 아니요, 모습만 바뀌어요. 대신 꾸미기 개수에 따른 업적과 레벨 미션 조건이 있어요.

**Q. 로그인을 안 해도 되나요?**
A. 네. 혼자 하는 모든 기능은 로그인 없이 할 수 있어요. 랭킹·친구·황금 붕어빵만 카카오 계정 로그인이 필요해요.
