### 이번 수정과 기술 검증 범위

- 초대 repository/시뮬레이터 분리, 단계별 이벤트·eventId 중복 방지, 활성 미션 이후 인정, 일일 상대별 보상, 코드·복사·OS 공유·현황을 추가했다. 공개 근거가 확인된 보상 종류 메타데이터와 추정 운영 정책을 분리했다.
- 꾸미기 4슬롯과 자체 미리보기/구매/장착, 가상 전체·친구 랭킹, 모의 이벤트의 기간/참여/선행 단계/재고/수령을 구현했다. 외형 변경 repaint 누락도 수정했다.
- 이벤트 표시는 화면별 상수 대신 같은 config/현재 재고를 사용하며, 홈 카운트다운도 컨트롤러의 역행 방지 시각을 사용한다.
- JSON 저장 스키마 v6, v1~v5 마이그레이션; 기존 SQLite 테이블/SQL schema 1 유지. 코인·초대·꾸미기·이벤트는 스냅샷 트랜잭션으로 함께 저장/롤백한다.
- 자동 테스트는 모의 시간/저장소와 직렬화 계약을 검증한다. 서버 검증·전역 동시 선착순·장기간 메모리/FPS·OS 수신 앱별 공유·iOS는 검증하지 않는다.
- 작업 재개 시 NUL로 채워진 소스/테스트 3개를 발견해 `build/recovery-null-20261005`에 원본 백업한 뒤 복구했다. 손상 원인은 단정하지 않는다. 복구 직후 기존 및 초대 테스트 130개가 통과했다.

## 데스크톱 모바일 확인 환경

- Android Emulator 설치 완료
- Android 15(API 35) 기본 x86_64 시스템 이미지 설치 완료
- Pixel 5 프로필 `TodayBungeoppang_API35` 생성
- 실행 스크립트: `tools/run_android_emulator.ps1`
- BIOS CPU 가상화는 활성화됨
- Android Emulator Hypervisor Driver 패키지는 내려받았으나 관리자 권한 설치가 완료되지 않아 `-accel-check` 결과 6이 유지됨
- 소프트웨어 가속 부팅은 장시간 offline 상태가 되어 실기기 설치 테스트를 완료하지 못함

관리자 PowerShell에서 다음을 한 번 실행한 후 재부팅하면 됩니다.

```powershell
C:\Android\sdk\extras\google\Android_Emulator_Hypervisor_Driver\silent_install.bat
```

이후 프로젝트 폴더에서 다음 명령으로 에뮬레이터를 열고 최신 APK를 자동 설치할 수 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\run_android_emulator.ps1
```
