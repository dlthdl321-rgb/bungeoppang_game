## 범위

| 요구 | 구현 |
|---|---|
| 탭 위치 +N | `onTapDown` 위치에서 떠오른다. 키보드·접근성·길게 누르기는 붕어빵 중앙에서 뜬다. 최대 `maxFloatingGains`(8)개 |

| 축하·카운트업 | 레벨업, 일일·주간 미션 보상, 업적, 아이템 사용 때 컨트롤러가 일회성 `GameEvent`를 보낸다(저장 성공 후에만, 저장하지 않음). `CelebrationHost`는 Navigator 위에 있어 바텀시트 위에도 배너, 아이콘, 카운트업(BigInt 정수 단계, 마지막은 정확한 값), 색종이(풀 36개)를 보여 준다. 여러 개는 순서대로 나온다 |
| 사운드 | 탭·구매·보상·레벨업 효과음과 24초 BGM 루프를 `tools/generate_sounds.py`로 직접 합성했다(CC0, README에 기록). `audioplayers` 6.8.1(MIT): 효과음은 `AudioPool`, BGM은 반복 재생. 오디오 포커스는 다른 앱 음악과 섞이도록(mixWithOthers) 했다. 탭 소리는 60ms 간격으로 제한한다 |
| 설정·저장 | 효과음·배경 음악 토글과 볼륨(0~100% 정수). 슬라이더는 끄는 동안 저장하지 않고 손을 뗄 때 한 번 저장한다. **저장 v8**: v1~v7은 기본값(켬, 70%, 40%)을 받고, v8은 타입·범위가 잘못되면 손상으로 거부한다 |
| 백그라운드 | inactive·hidden·paused에서 BGM을 멈추고 resumed에서 다시 재생한다(설정이 켜져 있고 볼륨이 0보다 클 때) |
| 오프라인 보상 | `AlertDialog`를 `OfflineRewardDialog`로 바꿨다. 그라데이션 패널, 붕어빵 그림, 비운 시간(상한 적용 후), 받은 양 카운트업, 규칙 안내(50%, 최대 `maxOfflineMs` 시간), 보상 효과음 |

## 잔여 위험

- **빌드 환경**: 이제 release 빌드에 영문 경로 Pub 캐시가 필요하다. CI나 다른 PC에서도 같은 조건이 필요하다.
- **BGM 기본값 "켬"(40%)**: 처음 실행부터 음악이 나온다. 설정에서 끌 수 있다. 다른 앱 음악과 섞이도록(mixWithOthers) 했으므로 사용자의 음악 앱과 동시에 들릴 수 있다.
- WAV 파일이라 앱 크기가 약 1.1MB 늘었다(OGG 인코더가 없어 WAV를 썼다).
- `audioplayers`가 `http`를 전이 의존성으로 가져온다. 앱은 로컬 에셋만 쓰고 권한은 없다. 그래도 나중에 URL 재생 코드를 추가하면 인터넷 권한과 데이터 보안 답변을 다시 검토해야 한다.
- 콤보 보너스를 켜면 경제 밸런스와 랭킹(누적 생산) 공정성에 영향이 있다. 켜기 전에 시뮬레이션이 필요하다.
- `share_plus`의 Kotlin Gradle 플러그인 경고가 계속 나온다(9단계와 동일).
