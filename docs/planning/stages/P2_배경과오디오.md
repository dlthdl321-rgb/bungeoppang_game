# P2 배경·오디오

2026-10-14 / 구현 전 계획·게임 검수 미실행.

## 목적과 규칙

독립BGM/굽기/SFX와영업/앱상태를분리한다.

명시BGM은배경/밤과독립저장,굽기루프는실제 굽기소스/전경기준,효과음은확정이벤트기준으로동작한다. 새5단계의활성구간·auto이전기본은DEC-008.

기본아바타외꾸미기/배경분류는레벨해금대상이며오디오설정/기능잠금과구분한다. BGM설정까지자동잠금하지않고정확접근범위를DEC-024에서정한다.

광고진입/종료의BGM/굽기/SFX중단·복원과영업지속을구분한다. 광고중게임시간은미정이며동일소리를중복재생하지않는다. [광고계약](../11_하루2회보상형광고.md)을따른다.

## 예외·저장·미정

영업중앱종료로붕어빵력이쌓여도오디오/센서를계속돌리지않는다. 비활성/출력실패/중복루프/빠른선택·저장실패를검수한다.

한국어·국내 Android·현재 도구 유지와 신규 문구 공통 관리/이미지 글자 분리 원칙을 이 단계에도 적용한다.
