## 1. 구분과 유지 원칙

- **기존 구현**: 코드에서 확인한 v12 클리커·경제·저장·오디오·지갑 기반. 문서·테스트 파일 존재는 동작 성공 근거가 아니다.
- **사용자 확정**: 최신 제작·숙련·도감·영업 요구, 팥 기본 레시피, 다른 맛은 상점/미션에서 간헐적으로 획득, 한국어·국내 Android 우선, 현재 도구 유지.
- **밸런스 초안/작성자 제안**: 기존 직접 탭·자동 효과 수치와 구현 방식 후보. 이번에 새 가격·횟수·보상·시간 수치를 만들지 않는다.
- **미결정**: 아래 DEC 표에서 관리한다. 확정과 일부 미정이 함께 있는 항목은 분리해 읽는다.

## 4. 확정 규칙

팥만 기본 보유한다. 팥도 숙련 전에는6구 생산할 수 없다. 다른 맛은 레시피 획득 **AND** 해당 숙련 완료 후 무작위 후보에 추가한다. 한 번 만들었다는 기록만으로 도감 완성/해금하지 않는다. 레시피 획득만으로 큰 틀 연습·직접 제작/판매가 가능하며 별도 레벨/누적 조건으로 막지 않는다.

도감은 맛마다5단계 익힘을 구분한다. 요구 연습량과 설정된 숙련 조건을 모두 채워야 정식 완성한다. 발견 기록·개별 도감 칸 등록·전체 완성은 별도다. 5종을 각1회 만들면 자동 완료한다는 규칙은 없다.

손님은 고유 대기시간을 가지며 줄에서 기다리는 동안에도 소모한다. 즉석 제작 중에도 대기시간이 흐른다. 재고 판매와 즉석 판매는 함께 쓸 수 있고 숙련 전 즉석 판매도 가능하다.

재고는 제작 당일0일, 이후 실제 영업한 새 날짜마다 나이+1,5영업일 경과 시 제거한다. 월요일 제작→화요일 영업=1일→미접속 후 토요일 영업=2일이다. 같은 날짜의 재접속/재영업은 중복 노화하지 않는다.

영업 중 앱 종료는 영업 종료가 아니다. 자동 붕어빵력은 영업 중에만 생산되며 오프라인 복귀 시 정산한다. 기존 **오프라인 최대8시간·접속 중 생산의50%** 규칙을 유지한다. 4시간 제한·오프라인 재고 지급·자동 수확을 도입하지 않는다. 이탈 제작/손님/6구 처리와 영업 상태 유지는 별도 문제다.

## 추가 확정: 복합 경제·50레벨·기능 해금

상점 상품과 스킬은 두 재화를 함께 요구하며 상품/스킬별 두 비용은 독립 설정한다. 충전 IAP는실제 결제다. 손님 판매 완료 시 드물게 황금붕어빵력을 보상으로 받으며, 별5개 만점인 판매 만족도가 높을수록 드롭 확률이 올라간다. 5점 확정 지급은 아니고 가격/확률/지급량/산정식은 미정이다.

첫 릴리즈 만렙은50이다. 꾸미기는기본 아바타만 제공하고 나머지꾸미기·도감·친구 기능은 일정레벨 이후 개방한다. 각 레벨/기능의 구체적인 표·기존 사용자/환생 적용·초기 황금 잔액이없는 사용자의 성장 경로는 결정 필요다. 보유레시피 큰틀연습/숙련전판매·숙련후6구 규칙을별도기능잠금과혼동하지않는다.

원본 계약과 기술 한계는 [복합 경제·50레벨](10_복합경제와50레벨해금.md)을 따른다.

### 하루2회 광고 보상 확정

황금획득은IAP·판매희귀·선택형보상광고세경로다. 광고는하루최대2회이며지급량/SDK는미정이다. 기존광고금지는이번사용자지시로해당형식만예외,일반분석/추적·강제전면/배너까지허용하지않는다. 일일광고키는영업일과별도이며KST자정재사용안은추천/미정으로구분한다. [광고계약](11_하루2회보상형광고.md)을따른다.
