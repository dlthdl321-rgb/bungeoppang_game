## 문서의 기준과 현재 상태

코드는 현재 구현, 사용자 최신 확정은 목표 계약이다. 미정 수치는 없애거나 미정으로 두며 작성자 제안을 완료/확정으로 격상하지 않는다. 요구번호REQ-01~07·단계P1~P6·작업P1-001·결정DEC-001·검수AC-REQ01-701 형식을 유지한다. 신규 세부 검수는701번대로 구분하고 이전 검수는 보관본의 과거 정의로 남긴다.

리얼 붕어빵은 영업일별 재고, 붕어빵력은 기존 생산 재화, 황금붕어빵력은IAP충전/만족도판매희귀/하루2회선택형광고보상재화다. 상점/스킬은붕어빵력과황금붕어빵력의AND비용이다. 도감은 영구 발견/완성과 재고 수량을 분리한다. 영업일·경제 부재시간·손님 대기시간은 서로 다른 시계다. 현재코드는v12·Lv.1~10기반이며신규숙련/운영/제품묶음·두재화결제·별5개만족도희귀황금·50레벨/기능잠금은미구현이다.

현재 결정은 [DEC 관리](00_공통기준.md#5-결정-관리)가 단일 기준이다. 모든 맛은 레시피 보유AND숙련 후6구랜덤후보이며 팥도예외없다. 영업중종료에도붕어빵력정산,8시간/50%유지,자동수확없음,실제영업일5일소멸을 구분한다.

## 체크리스트 운영

작업 이름을 누르면 상세·선행·관련 기획으로 이동한다. 상태·검증·예상시간의 원본은tasks.json, CHECKLIST/진행현황은 자동 생성이다. 원장 변경은 지정 담당/최종 통합 담당만 수행하고 이력의 과거 줄은 수정하지 않는다.

```powershell
python tools/planning_tasks.py render
python tools/planning_tasks.py list --status "미착수"
python tools/planning_tasks.py update P1-001 --status "진행 중" --owner "개발 담당자"
```

상태 변경 예시는 실제 착수 때만 실행한다. 완료는 구현 근거·실행 결과·선행 완료가 필요하며 문서 작성만으로 완료하지 않는다. 미산정 시간과 재산정 필요를 숫자0으로 취급하지 않는다. 이번 개정 전101시간은 참고값이며 새 전체 작업량/날짜는 미정이다.
