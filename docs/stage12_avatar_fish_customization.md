# 12단계 — 아바타 꾸미기 / 붕어빵 꾸미기 분리

작성: 2026-10-05~06. 시작 기준: 커밋 `e862e61 stage11: balance and endgame`(테스트 281개). 진행 중 별도 작업인 도트 전환이 `dac84d4 pixel art conversion`(테스트 283개)으로 먼저 커밋되었고, 구현은 그 위에서 했다.
실행 환경: `B:` subst, `PUB_CACHE=C:\PubCacheBungeoppang`, Flutter `C:\flutter-sdk\bin\flutter.bat`.

> **상태: 구현 완료.** 제안은 "제안대로" 승인되었다. 단, D1(그림 방식)은 승인 직후 도트 전환이 발견되어 사용자 확인을 거쳐 **도트**로 바꿨다(아래 승인 기록). 테스트 283개 → **298개**, 모두 통과.

## A. 분류와 슬롯 구조

`CosmeticCategory { bungeoppang, avatar, stall }`를 추가하고, 슬롯마다 분류 하나를 매핑한다(`slot.category`).

| 분류 | 화면 이름 | 슬롯(enum) | 슬롯 이름 | 기본값 id | "없음" 허용 |
|---|---|---|---|---|---|
| bungeoppang | 붕어빵 | `fish`(유지) | 맛 | `redbean` | 아니오 |
| | | `pattern` | 무늬 | `scales` 기본 비늘 | 아니오(기본 비늘이 곧 기본) |
| | | `topping` | 토핑 | `plain` 토핑 없음 | **예** |
| avatar | 사장님 | `hat` | 모자 | `nohat` 모자 없음 | **예** |
| | | `hair` | 머리 | `short` 짧은 머리 | 아니오 |
| | | `outfit` | 옷 | `apron` 기본 앞치마 | 아니오 |
| | | `tool` | 도구 | `tongs` 붕어빵 집게 | 아니오 |
| stall | 가게 | `background` / `stove` / `decoration` | 배경 / 화로 / 장식 | 기존 그대로 | 장식만 예(기존) |

- `fish` enum 이름은 바꾸지 않는다(저장·장부·테스트 키 호환). 화면 라벨만 '붕어빵'에서 '맛'으로 바꾼다.
- 포장지 슬롯은 넣지 않는다. 굽는 동안 붕어빵을 가려서 탭 대상이 어색해진다.
- 아바타 표정 슬롯은 넣지 않는다. 탭 동작과 레벨업 때 표정이 자동으로 바뀌는 연출로 대신한다.
- 피부톤 선택은 결정 D5에서 정한다.

## D. 구현 방향 요약 (제안 당시, 그림 부분은 아래 E가 우선)

- **저장(v10)**: 신규 슬롯 7개는 `WardrobeState`에 넣는다. 붕어빵 맛은 옛 필드를 유지한다(결정 D2).
  - v9 이하 세이브는 신규 슬롯을 기본값으로 채우고 기본값을 보유 목록에 넣는다.
  - v10은 지금처럼 엄격하게 검증한다.
  - 신규 항목 장부 ID는 `cosmetic:<id>`다.
- **그리기**:
  - `FishPainter`에 `pattern`과 `topping`을 추가한다. 비늘 루프를 무늬별로 나누고, 토핑은 몸통 clip 안에 맨 마지막으로 그린다.
  - 새 파일 `lib/ui/avatar_painter.dart`를 만든다. 레이어 순서는 몸 → 옷 → 머리 → 모자 → 손·도구다.
  - 홈 `Stack`에서 가게 배경 위, UI 아래에 별도 `RepaintBoundary`로 놓는다. 위치는 카운터 뒤 오른쪽(가로 0.70~0.97, 상반신만 보임)이다. 이렇게 하면 화로(0.20~0.68)와 가운데 탭 대상을 가리지 않는다. 눈사람 장식은 카운터 위, 사장님 앞에 그대로 그려진다.
  - 붕어빵을 탭하면 집게를 드는 0.25초 동작을 한다. `reduceMotion`·접근성 설정이 켜져 있으면 정지 상태로 둔다. 진동·소리는 기존 설정을 따른다.
- **UI**: `WardrobePanel` 맨 위에 [붕어빵][사장님][가게] 탭, 그 아래에 해당 분류의 슬롯 칩.
  - 미리보기는 분류마다 다르다. 붕어빵은 확대해서, 사장님은 상반신을 크게, 가게는 지금의 전경으로 보여준다.
  - 미리보기에서는 장착하지 않고 입혀 볼 수 있다(지금의 `preview` 동작을 분류마다 유지).
  - 해금 알림과 축하 화면 문구에 분류를 붙인다("새 사장님 옷", "새 붕어빵 토핑").
- **밸런스**: `economy_simulation_test`의 "가장 싼 꾸미기 구매"는 그대로 둔다. 세 시드 결과 표를 이 문서에 추가한다.

## E. 구현 결과

### 데이터·저장

- `CosmeticSlot`을 화면 순서대로 11개로 늘렸다: `fish(맛) pattern topping | skin hair outfit hat tool | background stove decoration`. 분류는 `slot.category`로 얻는다.
- `CosmeticDefinition.collectible`: 슬롯 기본값과 피부톤이 아니면 수집 대상이다. 유료 항목은 정확히 수집 대상과 같다(테스트로 단언). `free` 항목은 처음부터 보유한다.
- 저장 `formatVersion` 9 → **10**. `WardrobeState.fromJson(legacy: version < 10)`가 처리한다.
  - v6~v9 저장은 신규 슬롯을 기본값으로 채우고, 신규 슬롯의 무료 항목(기본값·피부톤 3종)을 보유 목록에 넣는다.
  - v10은 지금처럼 엄격하다. 빠진 슬롯, 보유하지 않은 장착, 모르는 ID, 다른 슬롯의 ID를 거부한다.
- 붕어빵 맛은 옛 필드와 원장 ID `skin:<id>`를 유지했다. 신규 항목의 원장 ID는 `cosmetic:<id>`다.
- 레벨업 알림(`GameEvent.details`)에 그 레벨에서 열린 꾸미기를 분류별로 한 줄씩 붙인다. 예: Lv.2 "새 사장님 꾸미기 · 묶은 머리, 털 비니".

### 그림 (도트)

`tools/draw_pixel_assets.py`(`--only fish,topping,avatar`)가 그리고, `lib/ui/pixel_sprites.dart`가 읽는다.

| 대상 | 파일 | 방식 |
|---|---|---|
| 무늬 | `fish/<맛>@<무늬>.png` (6맛 × 3무늬 = 18장, 64×48) | 비늘 자리에 무늬를 넣어 맛별로 미리 굽는다. 기본 비늘은 기존 `fish/<맛>.png` 그대로(바이트 동일) |
| 토핑 | `topping/<id>.png` (4장, 64×48) | 맛과 무관한 겹침 레이어. 등 윗부분에만, 얼굴은 피한다 |
| 사장님 | `avatar/{skin,hands,outfit,hair,hat,tool}/<id>.png` (19장, 44×60) | 몸(머리·목) → 옷 → 머리 → 모자 → 도구 → 손 순서로 겹친다. 손을 도구 위에 그려 집게를 쥔 모습이 된다 |

- 팔레트에 피부톤용 2색을 추가했다(`tan #D9A07A`, `umber #8A5536`). 피부톤 3단계는 cream/peach/tan, peach/tan/toast, tan/umber/wood_dark 조합이다.
- 장면 배치: 사장님 캔버스 좌상단을 (118, 250)에 둔다. 화로(30~110) 오른쪽이고, 카운터(y 304)가 아래쪽을 가린다. 사장님은 배경 다음, 카운터·화로·장식보다 먼저 그린다. 그래서 눈사람 장식은 사장님 앞에 놓인다.
- 탭 동작: `StallScene`이 `records.lifetimeTaps` 변화를 보고 0.25초 동안 `lift = sin(πt)`로 움직인다. 몸은 최대 2px, 집게는 3px 더 오른다. 모션 감소 설정이면 0이다.
- 홈 골든 3장(360/390/412)을 갱신했다. 사장님은 탭 대상 붕어빵과 오른쪽 메뉴 버튼과 겹치지 않는다. 360×800에서는 하단 카드가 상반신 아래쪽을 가린다.

### UI

- 꾸미기 화면: 맨 위에 `SegmentedButton` [붕어빵][사장님][가게], 그 아래에 분류의 슬롯 칩.
