# 경제 시스템 재구성

## 범위와 공개 근거

이번 단계는 경제 규칙·상점·저장 마이그레이션이다. 홈 그림과 기존 메뉴를 유지한다. 일일/초대 미션, 실제 랭킹·외부 계정·현금 지급은 구현하지 않았으며 기존 모의 안내를 유지한다.

2026-09-29 확인한 [세종라이프 공개 후기](https://dailysejong.tistory.com/entry/당근마켓-붕어빵게임-공략-총정리레벨-10-달성)는 레벨 6~10의 초당 생산 목표를 각각 1,500만 / 5억 / 200억 / 5,000억 / 20조로 기록한다. 공식 명세가 아닌 후기라는 한계를 config에도 명시했다. [당메 공개 후기](https://d-dangme-b.tistory.com/entry/당근마켓-붕어빵-게임-공략-및-레벨-정보-현금-7000원-인출-가이드)의 반복 강화·상위 스킬 성장 구조를 참고했다.

정확히 검증되지 않은 모든 가격·효과·가격 비율·해금·강화 상한, 초반 레벨 목표·누적 목표·레벨 보상은 **추정값**이다. 원작과 같은 가격 또는 같은 달성 시간을 보장하지 않는다. `lib/economy_config.dart`에서 숫자 문자열로 개별 수정하며 근거와 추정 여부를 구분한다.

## 구현

- 클릭/자동 생산 각 16단계(32개). 초기 6개 스킬의 ID·가격·효과는 유지한다. 다음 단계 효과는 최소 5배, 추가 단계는 10배씩 증가한다.
- 동일 스킬 최대 1,000회 강화. 이 상한은 메모리·최대 구매 탐색을 제한하는 추정 설정이며 UI에도 표시한다.
- n개 보유 시 다음 가격: `ceil(baseCost × numerator^n / denominator^n)`. 묶음 가격은 각 개별 가격을 올림한 뒤 더한다. 묶음 전체를 한 번만 올림하지 않는다.
- BigInt 가격 누적합을 지연 캐싱하고 지수 상한 탐색 + 이진 탐색으로 최대 수량을 계산한다. 보유량·수량 인덱스는 int, 모든 재화·가격·효과·보상·시간 정산의 분자는 BigInt이다.
- 1개 / 10개 / 최대 선택. 강화 상한 직전에는 실제 남은 수량을 표시한다. 종류별 목록, 현재 생산량·구매 후 생산량·가격, 구매 가능 강조, 누적 생산 해금 조건 및 정확한 전체 자릿수 다이얼로그를 제공한다.
- 만·억·조·경·해·자·양·구·간·정·재·극까지 표기한다. 10^52 이상은 `1.00e52` 형식으로 표시한다. 요약만 소수 둘째 자리까지 버리며 실제 값은 변하지 않는다. 전체 숫자는 정확한 가격 보기에서 확인한다.
- 생산 정산은 TimeService를 유지한다. 구매 직전 미정산 시간을 먼저 처리한다. 저장 실패 시 비용·스킬·보상을 복구하고 저장 중 중복 구매를 막는다. JSON 스냅샷의 스킬 맵을 복사해 이후 상태 변경의 영향을 받지 않게 한다.
- 10초 자동 저장 및 구매 시 저장 정책을 유지하며 프레임마다 저장하지 않는다.

## 저장 호환성

저장 본문 `formatVersion`과 `balanceVersion`을 2로 올렸다. SQLite의 기존 `snapshots` 테이블과 current/backup 트랜잭션 구조는 바꾸지 않는다. SQL 테이블 구조 버전은 1을 유지하고 JSON 본문 버전으로 마이그레이션한다.

v1의 기존 6개 스킬(유효 범위 0~25), 보유/누적 재화, 보상, 레벨, 외형, 설정, 시간·정산 나머지를 보존한다. 신규 26개 스킬은 0으로 추가하고 다음 저장에 v2를 기록한다. 기존 높은 레벨을 새로운 목표 때문에 낮추지 않는다. v1 백업도 읽을 수 있다. 미지원 버전과 손상된 필수 스킬은 초기화하지 않고 오류 처리한다. **v2 저장을 구버전 앱으로 역변환하는 기능은 없다.**

## 시뮬레이션

주입한 가상 시계로 매초 2회 클릭하고 구매 가능한 스킬 중 한계 생산/가격 비율이 가장 높은 것을 즉시 구매한다. 비율 비교도 BigInt 교차 곱이다. 이 정책은 검증용이며 사람의 예상 플레이 시간이 아니다.
