붕어빵 클리커 개발 에셋 패키지

이 패키지는 대화에서 생성한 이미지 전체와 개별 화면/모션 컷, GIF 재생 미리보기를 모은 자료입니다. 원본 그림은 변경하지 않았고 시트 분할과 재생 미리보기만 수행했습니다.

폴더
01_원본전체: 선택안과 이전 수정안 모두 보존. 미분류 2장은 중단된 생성과 연관될 수 있어 채택하지 않았습니다.
02_배경: 날씨/계절 6종 화면. 붕어빵이 합쳐진 시안입니다.
03_날씨프레임: 테마별 3컷, 총 18컷.
04_조리프레임: 준비→반죽→닫기→굽기→꺼내기→포장 6컷.
05_손님프레임: 등장→접근→도착→주문→수령→퇴장 6컷.
06_착용예시: 남녀 각 8종.
07_UI: 메인과 메뉴·설정·스킬·꾸미기·상점.
08_모션미리보기: 조리·손님·날씨별 GIF. 실제 스프라이트 애니메이션과 구분해야 합니다.

실제 구현 시 주의
- 원본은 AI 생성 컨셉 이미지입니다. 64×64를 목표로 한 초기 그림도 실제 64×64 PNG가 아닙니다. manifest에서 실제 크기를 확인하세요.
- 화면 UI 텍스트와 숫자는 이미지에 포함되어 있습니다. 레벨/보유량/초당/클릭당 값과 버튼은 Flutter 등의 위젯으로 다시 구현하세요. 값과 가격은 예시입니다.
- 모션 컷마다 몸·배경·작업대 위치가 조금 달라집니다. GIF는 시안 확인용이며 무보정 실사용 애니메이션이 아닙니다.
- 조리 원본은 RGBA이며 알파 채널이 있습니다. 어두운 미리보기만으로 불투명 배경이라고 판단하면 안 됩니다. 가장자리와 반투명 색상은 실제 배경 합성으로 점검하세요.
- 다른 캐릭터/의상 시트는 RGB 흰 배경이며 독립 투명 레이어가 없습니다. 꾸미기 연동에는 몸/머리/옷/소품을 공통 캔버스·기준점으로 다시 제작해야 합니다.
- 컷 분할은 균등 격자를 기준으로 각 경계 3px를 제외했습니다. 일부 흰 여백이 남을 수 있습니다. 손상 없는 원본도 함께 보존했습니다.
- GIF의 크기는 미리보기용 360×540이며 원본 컷 PNG를 개발 자료로 사용하세요.

권장 레이어 순서
배경 → 날씨 효과 → 거리 손님 → 매대/버너/틀 → 중앙 클릭 붕어빵 → 클릭 이펙트 → 오른쪽 하단 조리 컷 → HUD/메뉴.

클릭 연출 제안 (현재 새 이미지로 생성된 것은 아님)
중앙 붕어빵은 단일 투명 스프라이트에 scale 1.0→0.94→1.06→1.0 변화를 160~220ms 적용합니다. 작은 붕어빵 파티클은 위치/회전/크기/알파로 위로 솟게 합니다. 별도 점프 컷은 이번 대화에서 완성되지 않았습니다.

개발 전 추가 제작 목록
1. 중앙 붕어빵 투명 단일 에셋과 빈 배경 6종을 최종 구도로 제작.
2. 가스 조리대를 틀/덮개/버너 불꽃 레이어로 분리.
3. 여자·남자 조리 모션을 같은 캔버스와 피벗으로 제작. 현재 남자 조리 6프레임은 없음.
4. 손님 전면/후면 보행 스프라이트를 배경 없이 제작하고 이동·스케일로 접근 표현.
5. 날씨는 고정 배경에 입자 효과로 구현. 배경 컷 교체는 건물 흔들림이 생길 수 있음.
6. 꾸미기 의상별 팔 동작과 가림 순서 검증. UI 버튼은 실제 터치 영역으로 구현.

manifest.json은 각 파일의 출처·크기·분할 좌표·SHA-256과 애니메이션 순서를 제공합니다. 갤러리 HTML을 브라우저로 열면 패키지를 훑어볼 수 있습니다.
